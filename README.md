# DesignFlow

Планировщик для творческих проектов с канбан-доской и календарём. На доске есть три колонки: «Запланировано», «В работе» и «Готово». Приложение написано на HTML, CSS и обычном JavaScript.

## Как открыть

1. Распакуйте `DesignFlow.zip`.
2. Откройте папку `DesignFlow` и дважды нажмите на `index.html`. Страница откроется в браузере. Для запуска не нужны VS Code, установки или сборка.
3. При первом запуске на доске будут примеры задач и проектов. Их можно редактировать и удалять.

Данные хранятся в браузере через localStorage. У открытого с диска файла и опубликованного сайта свои данные. Очистка данных сайта удалит сохранённую доску. Некоторые браузеры ограничивают сохранение для файлов, открытых с диска. Если появится сообщение об этом, используйте опубликованную версию. Для локальной проверки при установленном Python 3 можно выполнить `python3 -m http.server 8000` в папке проекта и открыть [локальную страницу](http://localhost:8000/).

## Как обновить предыдущую версию

Закройте вкладку DesignFlow и замените файлы в той же папке файлами из нового архива. Откройте прежний `index.html` в том же браузере. Если сайт уже опубликован, загрузите обновлённые файлы в тот же репозиторий и пользуйтесь прежним адресом. Формат сохранённых задач остался прежним.

## Как пользоваться

- **«＋ Новая задача»** открывает форму. У задачи есть название, описание, проект, статус, приоритет и срок. Кнопка **+** в колонке подставляет её статус.
- **✎ на карточке** позволяет отредактировать или удалить задачу. Статус можно также изменить через список **«Статус»** на карточке или перетащить карточку мышью в другую колонку. На телефоне используйте список.
- **+ рядом с «Проекты»** создаёт проект. Через **⋯** можно изменить имя и цвет или удалить проект. После удаления проекта его задачи видны в разделе «Все проекты» с пометкой «Без проекта».
- Выберите проект в боковой панели и при необходимости уточните выборку поиском, приоритетом или сроком. Фильтры можно сочетать. Индикатор выполнения показывает прогресс всего выбранного проекта или всей доски.
- Фильтр **«Просрочен»** показывает незавершённые задачи со сроком до сегодняшней даты.

## Календарь

- **Месяц** показывает задачи по дням в календарной сетке. Нажмите на число задач в ячейке, чтобы увидеть список под календарём. На телефоне число видно прямо в сетке месяца.
- **Неделя** показывает семь дней с понедельника по воскресенье и задачи на каждый из них.
- Стрелки листают недели или месяцы, **Сегодня** возвращает к текущей дате. Проект и фильтры действуют в обоих видах.
- Нажмите на задачу, чтобы открыть её для редактирования. Нажмите на свободное место ячейки дня в неделе или месяце, чтобы сразу открыть форму новой задачи с заполненным сроком. Кнопка **+** рядом со списком дел на день работает так же. Задачи без даты собраны в блоке **Без срока**.

Карточку задачи можно зажать мышью и перетащить в другой день недели или месяца. Срок изменится и сохранится автоматически. Можно перетаскивать и задачи из списка под календарём, в том числе задачи без срока. На телефоне срок можно изменить в форме задачи.

## Публикация на GitHub Pages

Для бесплатного GitHub Pages создайте **публичный** репозиторий. Выберите один из двух способов загрузки ниже, затем включите Pages.

### Загрузить файлы через сайт GitHub

1. Войдите в свой аккаунт GitHub и создайте публичный репозиторий `designflow`. При создании отметьте **Add a README file**, чтобы сразу появилась ветка `main`.
2. В репозитории откройте **Add file → Upload files**. Перетащите **содержимое** папки `DesignFlow`: `index.html`, `README.md`, папки `css`, `js` и `fonts`. Если виден скрытый файл `.nojekyll`, добавьте его тоже. Эта версия работает и без него. Нажмите **Commit changes**.
3. Проверьте, что `index.html` виден сразу на вкладке **Code**, рядом с папками `css` и `js`.

При таком способе на GitHub появится один коммит с загрузкой файлов. Для переноса всей истории воспользуйтесь вариантом ниже.

### Загрузить с сохранением истории Git

Рядом с папкой `DesignFlow` в архиве находится `DesignFlow-history.bundle` со всей локальной историей. Создайте на GitHub **пустой** публичный репозиторий `designflow` без README. Откройте терминал в распакованной папке, где лежит файл `DesignFlow-history.bundle`, и выполните команды ниже. Замените `ВАШ-ЛОГИН` своим логином GitHub.

```sh
git clone -b main DesignFlow-history.bundle DesignFlow-git
cd DesignFlow-git
git remote set-url origin https://github.com/ВАШ-ЛОГИН/designflow.git
git push -u origin main
```

Для отправки Git должен быть авторизован в вашем аккаунте. После отправки на вкладке **Code** будет доступна история коммитов.

### Включить Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**. Укажите ветку **main**, папку **/(root)** и нажмите **Save**.
3. После развёртывания откройте **Visit site** в разделе **Pages**. Для репозитория `designflow` адрес будет вида `https://ВАШ-ЛОГИН.github.io/designflow/`.

Включить Pages может владелец репозитория или пользователь с подходящими правами. Файлы из архива готовы к публикации. Для появления публичного адреса их нужно загрузить в репозиторий и включить Pages из авторизованного аккаунта. [Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Файлы проекта

- `index.html` — интерфейс доски и формы.
- `css/style.css` — оформление и адаптация под разные экраны.
- `js/data.js` — примеры и сохранение данных.
- `js/calendar.js` — календарь, навигация по датам и список дел на день.
- `js/app.js` — задачи, проекты, статусы и фильтры.
- `.nojekyll` — публикация статических файлов на GitHub Pages.

## Проверка

В браузере проверены создание, изменение и удаление задач и проектов, сохранение после перезагрузки, смена статуса через список, индикация просрочки, поиск и совместное применение фильтров. После удаления проекта его задача осталась на общей доске. При ширине 390 px доска перестроилась в один столбец без горизонтальной прокрутки.

В календаре проверены переключение видов, переходы между неделями и месяцами, возврат к сегодняшней дате, поиск, создание задачи на выбранную дату, перенос срока в другой месяц и сохранение после перезагрузки. На ширине 390 px месячная сетка сохраняет семь столбцов без горизонтальной прокрутки.

## Повторения и события

В форме задачи доступны тип и повтор — ежедневно, еженедельно, ежемесячно или ежегодно. Укажите первую дату. Будущие повторения видны при просмотре соответствующего периода календаря. Доска содержит исходные задачи и отдельно открытые или изменённые повторения.

Тип «День рождения» автоматически выбирает ежегодный повтор. Тип «Оплата подписки» выбирает ежемесячный повтор и открывает поле суммы в рублях. Над календарём показана сумма незавершённых оплат за отображаемый период с учётом фильтров. Фактическое списание выполняет сервис подписки. Приложение хранит план оплат локально и показывает его при открытии.

В коротком месяце повторение приходится на последний день. После февраля дата 31 возвращается в март. Для 29 февраля в обычном году используется 28 февраля.

Открывайте отдельное повторение, чтобы изменить срок, отметить его выполненным или удалить только его. Редактирование исходной задачи меняет будущие повторения, которые ещё не открывали отдельно. Удаление исходной задачи удаляет всю серию вместе с её исключениями.

В поле «Подзадачи» введите каждое небольшое действие с новой строки. Галочки доступны на карточке доски и в списке выбранного дня под календарём. У каждого повторения свои отметки.








## Время и быстрый ввод

В форме доступны время, категория и отдельные заметки. Категории отмечены цветной полоской и названием. Заметки раскрываются на карточке доски и редактируются в форме.

Автоматическое распознавание при вводе названия понимает «сегодня», «завтра», «послезавтра», даты вида «2.11.2027» или «2 ноября», время вида «13:00». Без года используется текущий год. Дата и время сразу подставляются в поля формы. Их можно исправить вручную. При удалении распознанной фразы автоматически заполненные поля возвращаются к значениям до ввода, если вы ещё не меняли их вручную.


## Напоминания

Укажите дату, время и интервал напоминания в форме. Проверка выполняется раз в 15 секунд, пока страница открыта. Напоминание показывается внутри приложения. В разделе «Напоминания» можно отдельно разрешить уведомления браузера.

При закрытом приложении или спящем устройстве доставка не гарантируется. Для фоновых push-уведомлений нужен отдельный сервис доставки и публикация с соответствующей настройкой. Если приложение открыто позже времени напоминания, оно покажет его до истечения часа после события. Время интерпретируется в текущем часовом поясе устройства. После перезагрузки актуальное напоминание может появиться снова.


## Главная страница «Мой прогресс»

Навигация по разделам расположена слева. На главной показаны прогресс категорий за текущую неделю, количество задач по дням недели, дела на сегодня и мини-календарь. Нажмите день мини-календаря для перехода к полному месяцу.

«Учёба» и «Работа» используют категории задач. «Личные дела» объединяют остальные категории и задачи без категории. Показатели учитывают сроки задач и повторения. В разделе «Мои настройки» можно указать имя или никнейм для приветствия. Поле необязательное. Чтобы вернуть «Привет!», очистите имя и сохраните. Настройка хранится в этом браузере вместе с задачами.


Разделы привычек и обзора недели, а также отмена последнего изменения удалены по запросу.

Во всём интерфейсе используется Inter. Файл шрифта и лицензия OFL включены в папку `fonts`, поэтому шрифт доступен без подключения к интернету.

## Короткая форма задачи

Создание и редактирование разделены на «Основное» и «Детали». На первом этапе доступны название, дата, время и статус. Задачу можно сразу сохранить. Вкладка «Детали» открывает тип, повтор, сумму подписки, напоминание, проект, приоритет, категорию и подзадачи. Описание и заметки раскрываются отдельно.

Переходы между этапами сохраняют введённое в форме. При ошибке приложение открывает этап с обязательным полем. Проверены быстрое создание, редактирование подписки и переход к незаполненным полям.
